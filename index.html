#include <cmath>

// Target function: f(x) = x^2 - 2
double f(double x) { return x * x - 2.0; }
// Derivative: f'(x) = 2x
double df(double x) { return 2.0 * x; }

int main() {
    double x = 1.0; // Initial guess
    double tol = 1e-6; // Tolerance
    
    while (std::abs(f(x)) > tol) {
        x = x - f(x) / df(x);
    }

    std::cout << "Root: " << x << std::endl;
    return 0;
}

Sürekli ve sürtünmesiz bir akış hattında iki farklı nokta ($1$ ve $2$) arasındaki enerji dengesi Bernoulli denklemi ile şu şekilde ifade edilir:

$$P_1 + \frac{1}{2}\rho v_1^2 + \rho g z_1 = P_2 + \frac{1}{2}\rho v_2^2 + \rho g z_2$$

Denklemdeki parametreler ve birimleri:

  • $P$: Statik basınç ($\text{Pa}$ veya $\text{N/m}^2$)
  • $\rho$: Akışkan özkütlesi ($\text{kg/m}^3$)
  • $v$: Akış hızı ($\text{m/s}$)
  • $g$: Yerçekimi ivmesi ($9.81 \text{ m/s}^2$)
  • $z$: Referans düzleminden yükseklik ($\text{m}$)

Eğer akış ekseni yatay ise ($z_1 = z_2$) denklem basitleşerek statik ve dinamik basınç toplamına dönüşür:

$$P_0 = P + \frac{1}{2}\rho v^2$$
